## Замечания

### 1. [MEDIUM] REQ-03 vs NS-02 — конфликт по фото

**Цитата REQ-03:**
> Поля, недоступные через API (номер, контракт, фото), оставить пустыми с placeholder.

**Цитата NS-02:**
> Фото игроков — API не предоставляет на бесплатном tier.

**Проблема:** REQ-03 требует placeholder для фото, а NS-02 исключает фото из scope. Два агента прочитают это по-разному: один добавит placeholder для фото в карточку, другой — нет.

**Исправление:** убрать "фото" из списка placeholder-полей в REQ-03 (оставить только "номер, контракт") или переформулировать NS-02 как "Загрузка и отображение реальных фото игроков" (тогда placeholder остается допустимым). Выбрать один вариант и привести REQ-03 и NS-02 в согласованность.

---

### 2. [MEDIUM] REQ-01 содержит реализационное решение

**Цитата REQ-01:**
> Получить данные о составе команды из football-data.org API (`GET /v4/teams/64`) — поля: `id`, `name`, `position`, `dateOfBirth`, `nationality`.

**Проблема:** указание конкретного HTTP endpoint (`GET /v4/teams/64`) — это реализационное решение (*как*), а не описание поведения (*что*). REQ должен фиксировать наблюдаемый результат.

**Исправление:** переформулировать REQ-01:
> `REQ-01` Система содержит данные о текущем составе команды: имя, позиция, дата рождения, национальность — для каждого игрока.

Конкретный источник (`football-data.org`, endpoint, team ID) уже зафиксирован в ASM-01 и CON-01 — дублировать в REQ не нужно.

---

### 3. [MEDIUM] ASM-02 содержит нерешенный вопрос вместо факта

**Цитата ASM-02:**
> API возвращает ~43 записи в squad (включая youth/reserve); нужна фильтрация или отображение всех.

**Проблема:** "нужна фильтрация или отображение всех" — это open question, а не assumption. ASM-* должен фиксировать факт, на который фича опирается, а не перечислять варианты решения.

**Исправление:** разделить на два артефакта:
- `ASM-02`: "API возвращает ~43 записей в squad, включая youth/reserve players."
- `DEC-03`: "Фильтрация vs отображение всех игроков из squad. Решение: [выбрать вариант]." Если решение пока не принято — зафиксировать как OQ в плане и убрать из ASM-02.
