## Замечания

### 1. MEDIUM — REQ-02: реализационное решение в scope

**Цитата:**

> `REQ-02` Карточки новостей располагаются в адаптивной CSS Grid сетке: 1 колонка на мобильных, 2 на планшетах, 3 на десктопе.

**Проблема:** `REQ-*` должен описывать *что* пользователь видит, а не *как* это реализовано. «CSS Grid» — конкретная технология реализации. Если завтра появится причина использовать flexbox или другой подход, REQ формально будет нарушен, хотя пользовательский результат идентичен.

**Исправление:** Вынести «CSS Grid» из REQ-02 в DEC (например, `DEC-03`). REQ-02 должен описывать только поведение:

```
REQ-02: Карточки новостей располагаются в адаптивной сетке: 1 колонка на мобильных, 2 на планшетах, 3 на десктопе.
```

Добавить:

```
DEC-03: Адаптивная сетка новостей реализуется через CSS Grid.
```
